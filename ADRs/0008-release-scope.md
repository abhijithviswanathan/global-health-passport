# ADR 0008: Synthetic development release boundary

Status: Accepted as engineering safety boundary.

## Decision
Continue the full user-requested build autonomously, retain unmet scope and deliver executable work with evidence. Restrict current data to synthetic adults while jurisdiction, partners and production ownership remain undecided.

## Consequences
This boundary does not redefine the full requested product as complete. No production-ready or compliance certification claim is justified; external release gates remain visible.
